# Earth imagery

`day.webp` is an optimized WebP copy of the Earth atmosphere/day texture distributed in the official
Three.js examples:
https://github.com/mrdoob/three.js/blob/dev/examples/textures/planets/earth_atmos_2048.jpg

Downloaded 2026-10-02 and converted to WebP quality 85. Bundled locally so the globe needs no third-party texture
request at runtime. It is illustrative geographic imagery, not current weather.
