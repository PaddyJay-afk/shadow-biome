# Shadow Biome

Research atlas of the **ultraterrestrial hypothesis**: Patrick Jackson’s Sphere Network, U.S. keep-away ranges, missing-person clusters, and Jacques Vallée’s case against the star-visitor story.

TanStack Start + React 19. Auth is off. Field notes stay in the browser (`localStorage`).

## Run

```bash
npm install
npm run dev
```

App listens on port 8080.

```bash
npm run typecheck
npm run build
```

## Map

- Cyan fibers = Sphere Network Type 1 / 2 / 3
- Amber rings = missing-person clusters
- Diamonds = field notes pinned to a dossier

Do not trespass. Observation from public land only.
